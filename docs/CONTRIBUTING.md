# Development Contribution Workflows

Follow this process when submitting enhancements.

---

## 🚦 Branching Model
- **Branches:** Create custom branches from development (`feature/feature-name`).
- **Commits:** Prepend descriptive prefixes:
  ```text
  feat(user): add profile avatar updates
  fix(payments): fix receipt downloads
  ```
- **PRs:** Code must pass `flutter analyze` compiler checks.
