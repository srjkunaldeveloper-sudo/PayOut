# Payout Super App

Welcome to Payout, a premium fintech mobile application built using Flutter. This project follows clean, production-ready architecture.

---

## 🚀 Getting Started

### Prerequisites
- Flutter SDK `3.22.x` or later
- Dart SDK `3.4.x` or later

### Installation
1. Clone the repository.
2. Run package resolution:
   ```bash
   flutter pub get
   ```
3. Launch development server:
   ```bash
   flutter run
   ```

---

## 📱 Features
- **OTP Verification & Authentication:** Fast onboarding with client stubs.
- **Wallet & Bank Accounts:** Direct balance monitoring and UPI integrations.
- **Mobile Recharge & Bill Payments:** Instant transaction routing for utilities.
- **Alerts & Transaction Histories:** Real-time push updates.
